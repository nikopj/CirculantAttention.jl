CirculantAttention

Circulant-sparse attention (CircAtt) performs query-key-value attention with a sliding-window mask,

\[Y = \mathrm{rowsoftmax}(M \circ S / \sqrt{\tau})\, V, \qquad S_{ij} = s(q_i, k_j),\]

where $s$ is a similarity between the channel vectors of queries and keys, $\tau$ is the number of channels, and $M$ is a mask with a circulant (1D signals) or block-circulant with circulant blocks (2D signals) sparsity pattern: every pixel attends to the pixels in a window of odd width centred on it, with circular boundary extension.

The package is CUDA only. Attention matrices are either materialized as sparse Circulant arrays or fused away by the flash functions, in the forward and the backward pass. Everything is differentiable with ChainRules/Zygote, including for complex-valued tensors. Window sizes must be odd.

Quickstart

using CUDA, NNlib, CirculantAttention

H, W, C, B = 128, 96, 64, 2
ws, nheads = 15, 4
q, k, v = CUDA.randn(H, W, C, B), CUDA.randn(H, W, C, B), CUDA.randn(H, W, C, B)

y, A = circulant_attention(DistanceSimilarity(), q, k, v, ws)  # output and adjacency
size(A)  # (H*W, H*W, 1, B)

y, A = circulant_mh_attention(DotSimilarity(), q, k, v, ws, nheads)
size(A)  # (H*W, H*W, nheads, B)

circulant_attention scales q and k by τ^(-1/4) each, computes the circulant_similarity, normalizes each row, and applies the result with ⊗:

t = sqrt(size(q, 3))
S = circulant_similarity(DistanceSimilarity(), q ./ sqrt(t), k ./ sqrt(t), ws)
P = NNlib.softmax(S)
P ⊗ v ≈ first(circulant_attention(DistanceSimilarity(), q, k, v, ws))  # true

Similarities

similarity$S_{ij}$
DotSimilarity$q_i^H k_j$
RealDotSimilarity$\mathrm{Re}(q_i^H k_j)$
DistanceSimilarity$-\frac{1}{2}\lVert q_i - k_j \rVert_2^2$
PIDotSimilarity$\lvert q_i^H k_j \rvert$
PIDistanceSimilarity$-\frac{1}{2}(\lVert q_i \rVert_2^2 - 2 \lvert q_i^H k_j \rvert + \lVert k_j \rVert_2^2)$

Normalizations

Wrapping a similarity replaces the row softmax by sparsemax (SparsemaxSimilarity), α-entmax (EntmaxSimilarity), or a softmax over the k largest entries (TopKSimilarity):

y, A = circulant_attention(EntmaxSimilarity(DistanceSimilarity(), 1.5f0), q, k, v, ws)

joint_softmax, joint_sparsemax, and joint_entmax normalize each row over the union of the windows of several matrices, e.g. a signal attending to itself and to a guide signal g with values vg:

S1 = circulant_similarity(DotSimilarity(), q, k, 5)
S2 = circulant_similarity(DotSimilarity(), q, g, 9)
P1, P2 = joint_softmax(S1, S2)   # rows of P1 and P2 together sum to one
y = P1 ⊗ v + P2 ⊗ vg

Flash attention

The flash functions fuse similarity, normalization, and application into single kernels with an online softmax, so the circulant-sparse matrix is never materialized and memory traffic drops from $O(NW^d)$ to $O(NC)$. Their backward passes recompute the attention weights from the logsumexp saved in the forward pass.

functioncomputes
circulant_flash_attentioncirculant_attention without the attention matrix
circulant_mh_flash_attentionmulti-head version
circulant_flash_joint_attentionseveral branches under a joint normalization

circulant_mh_flash_guided_joint_attentiona self branch plus guide branches sharing its query
circulant_flash_transposed_attentionthe transposed apply $\Gamma^\top x$
circulant_mh_flash_transposed_attentionmulti-head version

They accept the real-valued similarities (DotSimilarity on real inputs only) and, through fused α-entmax kernels following AdaSplash, SparsemaxSimilarity and EntmaxSimilarity. TopKSimilarity cannot be fused.

Circulant matrices

Circulant matrices of size (HW, HW, nheads, B) support +, -, broadcasting over their values (e.g. A + m .* B with m of size (1, 1, nheads, B)), sum(A; dims), cat(A, B; dims=3), and multi-head application A ⨷ x. windowview exposes their values as a dense (ws^d, HW, nheads, B) array.
