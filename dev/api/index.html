API

CirculantAttention.CirculantAttention — Module
CirculantAttention

Sliding-window ("circulant-sparse") attention for CUDA arrays: the attention matrix has a window of odd width around every pixel of a 1-D or 2-D signal, with periodic boundaries. It is either materialized as a Circulant matrix or fused into flash kernels. Also available as CircAtt.

source

Attention

CirculantAttention.circulant_attention — Function
y, A = circulant_attention(simfun::AbstractSimilarity, q, k, v, W::Int)

Perform circulant attention on y=Av, where A is a row-softmax normalized circulant-sparse attention matrix (A = rowsoftmax(S)). Each non-zero entry $S_{ij}$ is generated via the similarity function acting on the channel representations of q and k at (linearly indexed) pixels i, j ($S_{ij} = \mathrm{simfun}(q_i, k_j)$). Adjacency matrix $A$ is generated internal and returned as the second argument. Note: q and k are internally scaled by sqrt(sqrt(channels)) before being passed to circulant_adjacency.

See also circulant_adjacency, circulant_similarity, DotSimilarity, DistanceSimilarity.

CirculantAttention.circulant_mh_attention — Function
y, A = circulant_mh_attention(simfun::AbstractSimilarity, q, k, v, W::Int, nheads::Int)

Performs circulant multi-head attention, i.e., performing circulant attetion of nheads-groups separately and concatenating the result along channels. The number of channels in q, k, v must be divisible by nheads. The returned adjacency matrix A will have size(A, 3) == nheads.

See also circulant_attention, DotSimilarity, DistanceSimilarity.

Flash attention

CirculantAttention.circulant_flash_attention — Function
y = circulant_flash_attention(simfun::AbstractSimilarity, q, k, v, W::Int)

Fused (flash) version of circulant_attention: computes the same y = rowsoftmax(S)v with $S_{ij} = \mathrm{simfun}(q_i, k_j)$ in a single kernel using an online softmax, without ever materializing the circulant-sparse attention matrix — memory traffic is $O(NC)$ instead of $O(NW^d)$. Only y is returned; if the adjacency matrix is needed, use circulant_attention.

The backward pass is fused as well: attention weights are recomputed from the logsumexp saved during the forward pass (FlashAttention-style), so no sparse intermediate exists in either direction.

The similarity must be real-valued (RealDotSimilarity, DistanceSimilarity, PIDotSimilarity, PIDistanceSimilarity, or DotSimilarity on real inputs). SparsemaxSimilarity and EntmaxSimilarity are supported via dedicated fused α-entmax methods (see the EntmaxSimilarity/SparsemaxSimilarity methods of this function); TopKSimilarity renormalizes over the full window and is not fusable.

See also circulant_attention, circulant_mh_flash_attention.

source
y = circulant_flash_attention(es::EntmaxSimilarity, q, k, v, W::Int)
y = circulant_flash_attention(ss::SparsemaxSimilarity, q, k, v, W::Int)

Fused (flash) circulant α-entmax / sparsemax attention: computes y = P v where P is the row-wise α-entmax (resp. sparsemax = α-entmax at α=2) of the windowed similarities $S_{ij} = \mathrm{simfun}(q_i, k_j)$, without ever materializing the circulant-sparse attention matrix. Following AdaSplash (arXiv:2502.12082), the per-row entmax threshold is solved by a fixed-iteration Halley/bisection root-finder inside the fused loop; memory traffic is $O(NC)$ instead of $O(NW^d)$.

The forward returns only y; the backward is fused as well (q, k, v gradients are exact — α is a fixed hyperparameter and is not differentiated, as in the non-flash EntmaxSimilarity path). The inner similarity must be real-valued (see circulant_flash_attention).

See also circulant_attention, EntmaxSimilarity, SparsemaxSimilarity.

CirculantAttention.circulant_flash_joint_attention — Function
ys = circulant_flash_joint_attention(simfuns, qs, ks, vs, Ws)
ys = circulant_flash_joint_attention(simfun, q, k, v, Ws::NTuple{M,Int})

Fused (flash) version of joint-softmax attention: each branch $m$ computes circulant similarities with window $W_m$, the softmax is normalized jointly over the union of all branches' window entries per row (as in joint_softmax), and branch outputs $y_m = P_m^{joint} v_m$ are returned as a tuple — without materializing any attention matrix.

No additional kernel is involved: the joint softmax decomposes over the per-branch logsumexps the fused kernels already produce, $y_m^{joint} = e^{L_m - L^{joint}} \odot y_m$ with $L^{joint} = \mathrm{logsumexp}_m(L_m)$ rowwise, so this is the per-branch circulant_flash_attention plus dense reweighting. Branches may have different windows, inputs, and similarities, but must share spatial size and batch. Inputs are scaled by sqrt(sqrt(channels)) per branch as in circulant_attention.

The convenience form runs M branches with shared simfun, q, k, v and windows Ws.

See also joint_softmax, circulant_flash_attention.

source
ys = circulant_flash_joint_attention(sfs::NTuple{M,<:EntmaxSimilarity}, qs, ks, vs, Ws)
ys = circulant_flash_joint_attention(sf::EntmaxSimilarity, q, k, v, Ws::NTuple)

Fused (flash) joint α-entmax / sparsemax attention: the normalization is a single α-entmax over the union of all branches' window entries per row (as in joint_entmax / joint_sparsemax), computed without materializing any attention matrix. Returns a tuple of per-branch outputs. All branches share α (sfs[1].α; α=2 for SparsemaxSimilarity); inner similarities may differ per branch. Gradients w.r.t. qs,ks,vs are exact.

See also circulant_flash_attention, joint_entmax.

CirculantAttention.circulant_mh_flash_guided_joint_attention — Function
ξz, ξg = circulant_mh_flash_guided_joint_attention(simfun, qz, kz, vz, Wz,
                                                   kg, vg, Wg, num_guides, nheads)

Joint-softmax flash attention for the guided multi-guide proximal map: a single self branch (qz, kz, vz, window Wz) plus num_guides guide branches that share the self query and a common window Wg, with the guide keys/values stacked along the batch dimension of kg/vg as (guide-fastest, base-batch) (size(kg, end) == num_guides * size(kz, end)).

Equivalent to circulant_mh_flash_joint_attention over the branches (self, g₁, …, g_G) — the softmax is normalized jointly over the union of the self window and all guide windows — but the guides are attended in one batched flash call instead of one call per guide (and the caller projects them once). Returns the self output ξz and the summed guide output ξg = Σ_g ξ_g, each (spatial..., Cv, B).

See also circulant_mh_flash_joint_attention.

source
ξz, ξg = circulant_mh_flash_guided_joint_attention(sf::EntmaxSimilarity, qz, kz, vz, Wz,
                                                   kg, vg, Wg, num_guides, nheads)

Guided joint α-entmax / sparsemax flash attention: a self branch plus num_guides guide branches (sharing the self query qz, keys/values stacked guide-fastest in the batch dim of kg/vg), jointly normalized per row. Returns the self output and the summed guide output — i.e. circulant_mh_flash_joint_attention over (self, g₁…g_G) with the guide outputs summed.

CirculantAttention.circulant_flash_transposed_attention — Function
y = circulant_flash_transposed_attention(simfun::AbstractSimilarity, q, k, x, W::Int)

Fused (flash) version of the transposed circulant attention apply $y = \Gamma^{\!\top} x$, where $\Gamma = \mathrm{rowsoftmax}(S)$ with $S_{ij} = \mathrm{simfun}(q_i, k_j)$ is the same row-softmax attention matrix circulant_flash_attention applies as $\Gamma v$. The transpose is

\[(\Gamma^{\!\top} x)_a = \sum_r e^{\,s_{ra} - L_r}\, x_r ,\qquad L_r = \mathrm{logsumexp}_i\, s_{ri},\]

i.e. each source row keeps its own softmax normalizer $L_r$ — so a plain $q\leftrightarrow k$ swap does not give $\Gamma^{\!\top}$ (that would renormalize over the wrong axis). No attention matrix is materialized; gradients w.r.t. q, k, x are exact.

q, k must share shape; x carries the attended channels. The similarity must be real-valued. EntmaxSimilarity/SparsemaxSimilarity are supported via dedicated fused methods (see the EntmaxSimilarity/SparsemaxSimilarity methods of this function); TopKSimilarity is not fusable.

See also circulant_flash_attention, circulant_mh_flash_transposed_attention.

source
y = circulant_flash_transposed_attention(es::EntmaxSimilarity, q, k, x, W::Int)
y = circulant_flash_transposed_attention(ss::SparsemaxSimilarity, q, k, x, W::Int)

Fused (flash) transposed α-entmax / sparsemax apply $y = Γ^⊤ x$ where $Γ = \mathrm{row\text{-}entmax}(S)$. Like the softmax circulant_flash_transposed_attention, no attention matrix is materialized and gradients w.r.t. q, k, x are exact (α is a fixed hyperparameter).

source
CirculantAttention.PIDistanceSimilarity — Type
PIDistanceSimilarity()

Phase-invariant distance similarity: $S_{ij} = -\frac{1}{2}(\lVert q[i] \rVert_2^2 - 2 \lvert q[i]^H k[j] \rvert + \lVert k[j] \rVert_2^2)$.

CirculantAttention.TopKSimilarity — Type
TopKSimilarity(sim, k)

Keeps the k largest similarities sim of each row: circulant_similarity sets the others to -Inf, and circulant_adjacency (hence circulant_attention) applies the softmax over the remaining entries. Gradients treat the selection as fixed. Not supported by the flash functions.

source
CirculantAttention.SparsemaxSimilarity — Type
SparsemaxSimilarity(sim)

Normalizes the similarities sim of each row with sparsemax instead of the softmax, so that attention weights outside a data-dependent support are exactly zero. Supported by circulant_attention and the flash functions.

source
CirculantAttention.EntmaxSimilarity — Type
EntmaxSimilarity(sim, α)

Normalizes the similarities sim of each row with α-entmax instead of the softmax: α → 1 recovers the softmax and α = 2 sparsemax, and values in between give attention weights of intermediate sparsity. α is a fixed hyperparameter (not differentiated); for a learnable α, apply entmax to the output of circulant_similarity. Supported by circulant_attention and the flash functions.

Normalizations

CirculantAttention.sparsemax — Function
sparsemax(W)
sparsemax(A::Circulant)

Sparsemax (Martins & Astudillo, 2016) along the first dimension of W, or over the window entries of each row of A: the Euclidean projection onto the probability simplex, max.(W .- τ, 0) with the threshold τ chosen so that each column sums to one.

source
CirculantAttention.entmax — Function
entmax(W, α)
entmax(A::Circulant, α)

α-entmax (Peters et al., 2019) along the first dimension of W, or over the window entries of each row of A: max.((α - 1) .* W .- τ, 0) .^ (1 / (α - 1)), with the threshold τ (found by bisection) chosen so that each column sums to one. α ∈ (1, 2] is a number or an array broadcastable against W (e.g. one value per head); a scalar α ≈ 1 or α ≈ 2 gives the softmax or sparsemax. Differentiable in W and α.

source
CirculantAttention.joint_softmax — Function
joint_softmax(A₁, A₂, …)

Softmax normalized jointly over the window entries of several Circulant matrices: for every row (and head and batch index), the entries of all Aₘ together sum to one. The matrices must have the same size and may differ in window width. Returns a tuple of Circulants with the sparsity patterns of the inputs.

See also joint_sparsemax, joint_entmax, circulant_flash_joint_attention.

Circulant matrices

CirculantAttention.Circulant — Type
Circulant{T}(M, (spatial..., h, b))
Circulant(data, M, spatial_size)

Batched circulant-sparse matrix of size (P, P, h, b), where P = prod(spatial) is the number of pixels of a 1-D or 2-D signal and row i holds the M^S entries (S spatial dimensions) of the window of odd width M centred on pixel i, with periodic boundaries. The values are stored in a batched CuSparseArrayCSR (A.data) and exposed as a dense array by windowview.

Circulant{T}(M, dims) allocates one with all values one (T = Float32 by default); usually they come from circulant_similarity and circulant_adjacency. Circulant matrices support +, -, broadcasting over their values (e.g. m .* A with m of size (1, 1, h, b)), sum(A; dims), cat(A, B; dims=3), reshape and dot, and are applied to signals with ⊗ and ⨷.
